# Proyecto Daniela

Aplicación web para analizar lotes de producción de panadería, detectar cuellos de botella, sugerir cambios operativos y ejecutar una simulación Monte Carlo sencilla.

## Desarrollo

```bash
npm install
npm run dev
```

## Despliegue en Vercel

El proyecto usa Next.js App Router y no requiere configuración especial. En Vercel, importa este repositorio y usa los comandos por defecto:

- Build command: `npm run build`
- Output: automático para Next.js
